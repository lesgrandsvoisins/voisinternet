Le web est étrange. Nous avons essayé les systèmes de contenu suivants :

1. Wordpress
2. Wagtail
3. ApostropheCMS
4. HTML
5. Ghost.io
6. Plone
7. Odoo

Mais finalement, je pense que Ghost peut convenir.

Il y a beaucoup à ne pas aimer dans ghost.io. C'est un stack technologique très limitée: NodeJS et MySQL (version 8) par exemple. Pourtant, il semble avoir une approche native suffisamment orientée pour les besoins de raconter sereinement des histoires pour le web, comme  peut le faire Wordpress. Au contraire de Wordpress, nous ne pouvons que faire ce pour quoi est fait Ghost. Notamment, je ne vois pas de manière de relier les comptes Ghost avec les comptes centralisés des Grands Voisins: chose qui embête pour maintenant. Pourtant, si nous arrivons à écrire des choses intelligibles pouvant être lu par des tiers, cela me suffira.
